Cyber Toolkit

Two instruments, not two stories

Every CyberTrail case ends with advice like "use a unique password" or "check before you click." These are the actual tools behind that advice; the same kind of thinking an attacker's automated tools use, run in reverse, in your browser.

Instrument 01

Password Strength Meter

This estimates how hard a password would be to guess, based on its length and character variety. It cannot tell you if you've reused it somewhere else, which matters more than strength alone. A strong password that's been leaked in a breach is still unsafe.

—

    Nothing you type here ever leaves this page. There's no server involved since the whole check runs locally in your browser.

    Instrument 02

    Password Generator

    Built on crypto.getRandomValues(), not Math.random(), which isn't cryptographically secure and shouldn't be used for anything security-related. It's a common real-world mistake.

    A passphrase like this can be both stronger and easier to remember than a short random string; length matters more than complexity.

    Instrument 03

    Scam Message Scanner

    Paste in a suspicious email or text. This checks it against six independent warning signs and shows exactly what got flagged and why. However, it's a simple pattern scanner, not a trained spam filter, so treat a clean result as a starting point, not a guarantee.
